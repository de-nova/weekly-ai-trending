## 项目详情

### 1. ECC

**项目链接：** [affaan-m/ECC](https://github.com/affaan-m/ECC)

ECC 是一个面向 AI 编程 Agent 的性能优化与工程工作流系统。它将技能、记忆、安全约束和"先研究、后实现"的开发方法组织起来，可用于 Claude Code、Codex、OpenCode、Cursor 等不同智能体环境，帮助团队把复杂开发任务拆解为更可重复、可审查的流程。该项目支持多种编码智能体，目标是提高 Agent 在长期开发任务中的稳定性与效率。

---

### 2. Claude Code

**项目链接：** [anthropics/claude-code](https://github.com/anthropics/claude-code)

Claude Code 是 Anthropic 推出的终端型编码助手。它可理解代码库结构，并通过自然语言指令执行代码修改、调试、解释和 Git 工作流操作。项目适合希望在命令行中快速交互、减少重复操作的开发者，可作为日常编程的辅助工具。

---

### 3. Agent Skills

**项目链接：** [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)

Agent Skills 收集了由 Google Chrome 工程师 addyosmani 开源的 AI 编程技能库。内容覆盖 Code Review、需求澄清、测试编写、Git 提交等多个阶段，为 Codex、Claude Code 等智能体提供可复用的工程能力模块，帮助团队建立更规范的开发流程。

---

### 4. Paperclip

**项目链接：** [paperclipai/paperclip](https://github.com/paperclipai/paperclip)

Paperclip 是一款面向团队协作的 AI Agent 管理平台。它允许用户在应用中统一管理多个 AI Agent，监控其运行状态、配置权限和工作流程。项目适合需要集中管理 AI 工具、评估 Agent 性能以及协调多 Agent 协作的企业和开发团队。

---

### 5. Orca

**项目链接：** [stablyai/orca](https://github.com/stablyai/orca)

Orca 是一个面向并行 Agent 队列的 Agent Development Environment（ADE）。它支持在桌面、移动端和远程运行环境中使用自己的订阅运行编码 Agent，适合需要同时管理多个编码任务、观察执行进度并协调多个子 Agent 的开发者或团队。

---

### 6. Open Code Review

**项目链接：** [alibaba/open-code-review](https://github.com/alibaba/open-code-review)

Open Code Review 是阿里巴巴开源的代码审查工具，采用确定性流水线与 LLM Agent 相结合的混合架构。它提供精确到代码行的评论、多语言规则和面向规模化工程实践的审查能力，可帮助团队在自动化质量检查之外，引入大模型辅助的上下文分析。

---

### 7. Financial Services

**项目链接：** [anthropics/financial-services](https://github.com/anthropics/financial-services)

Financial Services 是 Anthropic 官方仓库中的金融服务相关开源资源，位于其组织账户下。本项目聚焦金融领域的应用场景，适合关注金融合规、风险管理和数据分析的智能体开发参考。

---

### 8. Hindsight

**项目链接：** [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight)

Hindsight 是一个专注于"可学习的 Agent 记忆"的项目，关注如何让 AI 智能体跨任务保存经验、检索历史上下文并从中学习。项目适合研究长期记忆、上下文恢复和连续任务执行的开发者，可为多轮对话、复杂工作流提供记忆能力支持。

---

### 9. Claude Code Templates

**项目链接：** [davila7/claude-code-templates](https://github.com/davila7/claude-code-templates)

Claude Code Templates 是一个命令行工具，用于配置和监控 Claude Code 会话。它提供模板管理和会话观察功能，帮助开发者批量管理 AI 编程任务、跟踪执行状态和优化 Agent 交互流程，提升日常编码效率。

---

### 10. WeKnora

**项目链接：** [Tencent/WeKnora](https://github.com/Tencent/WeKnora)

WeKnora 是腾讯开源的 LLM 知识平台，可将原始文档转化为可查询的 RAG、具备推理能力的 Agent 和可维护的 Wiki。它覆盖文档解析、检索、重排序、问答等知识服务链路，适合构建企业内部知识问答、文档检索和智能助手应用。
